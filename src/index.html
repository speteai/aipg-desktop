Holding AIPG: extra free credit every day

The tokens stay yours; the grid only reads the balance of your sign-in wallet on Base, at the last block before midnight UTC. The first allowance therefore comes the day after the tokens arrive. Each wallet counts on its own, balances are not added together. The network grants a limited total per day, so late in a day the allowance can be used up. The credit can only be spent on the grid; it cannot be withdrawn.

Connect

off

Let an AI assistant on this computer hand work to the grid: text tasks, image generation, model list and your credit. It runs locally as an MCP connector; nothing is hosted.

The connector is only available in the desktop app.

With an API key, enabling stores the key in a file in this app's data folder so the connector can use it; with the browser sign-in, the connector uses that sign-in instead. Whatever the assistant sends to the grid is billed to your account (your daily free allowance is used first when active).

Applies to what an assistant sends through the connector: keys, passwords, e-mail addresses, IBANs, card and phone numbers. Image prompts cannot be masked and are refused instead. Every answer is handed to the assistant marked as untrusted third-party content.

On: the assistant sees small images it generated. Off: it only gets the file paths; the images stay in the gallery. Off keeps third-party image content out of the assistant's conversation and saves its memory.

Coding tools

        
Use a grid model as the model of a coding tool. This is separate from the connector above: the tool
          talks to the grid directly with your API key, and everything it sends is billed to your account.

        
These tools need a Grid API key; the browser sign-in is not enough.
          

        

          
          

            
            
          

          

          
This model has a small context. Coding tools send 10,000 to 25,000
            tokens of instructions with every request, so it will lose part of them. Choose a model with a larger context.

        

        

          
          

          

            
            
            
          

          
In the tool, choose the provider type “OpenAI compatible” and enter these three values.

        

        

          
          

          

            
          

          

          

          
The text above shows a placeholder; the button copies it with your real key. Claude Code then
            runs on the grid model instead of Claude: expect weaker results on large tasks. Every request carries about
            23,000 tokens of instructions, so a short task costs roughly $0.002 to $0.004 at current prices. If Claude Code reports a conflict with an existing
            login, run /logout in it. Known limits: token counts are estimates, a request may hold at most
            200,000 characters, and the grid allows 30 requests a minute.

        

        
Privacy: a coding tool sends your source code and file contents to the grid, where they are
          processed in plain text on computers run by independent operators. The masking of private data that the chat and
          the connector apply does not apply here. Do not use this for code or files that must stay confidential.

Grid requests are answered on computers run by independent people. Before a chat message goes
          there, the app looks for keys, passwords, e-mail addresses, IBANs, card and phone numbers. Masking replaces
          them by placeholders and puts the real values back into the answer, so the other computer never sees them.
          It only catches clearly shaped values, not confidential text in general — use a “Local only” chat for that.
